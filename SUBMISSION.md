# Submission checklist

Tick each line before the host closes submissions.

- [ ] The repository is public and contains the licence file (`LICENSE`).
- [ ] `README.md` names the model, its size and a link to its licence or terms.
- [ ] If entering the Gemma prize: the project calls Gemma through the Gemini API, and the README says so.
- [ ] If the project is an agent: it runs as a standalone multimodal agent with zero external runtime dependencies.
- [ ] The README explains what the team built and how the model is used, in plain words.
- [ ] The submission lists the tools and assistance used to build the project, as the event rules ask.
- [ ] On the event page (OrganizerHQ Challenges): project link, name, description, technologies, demo URL, and every challenge ticked.
- [ ] One teammate submitted; everyone registered and checked in.
- [ ] The two-minute live demo has been run through once offline (`--offline` for the local engine).
- [ ] Hacking stops at the deadline; only tiny fixes after it.
